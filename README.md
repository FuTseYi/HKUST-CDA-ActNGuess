# HKUST-CDA-ActNGuess 🎭

港科广职协 · 你比我猜 — 一款为香港科技大学（广州）职业发展协会团建、迎新和破冰活动制作的多人限时肢体猜词游戏。

**零依赖、纯静态、开箱即玩。** 直接打开 `index.html`，或将仓库 `main` 分支部署到 GitHub Pages / Cloudflare Pages / Vercel。

## 功能

- **自备词库**：不预置词语，上传 UTF-8 编码的 TXT、CSV（每行一个词，无需表头），或直接粘贴；自动去重，最多 150 个词，每个词最多 18 个字。
- **分页操作**：赛前设置、游戏舞台、成绩排行独立显示；开始和结束回合时自动切换，游戏舞台适配一屏操作。
- **明亮黄蓝界面**：白底、深蓝文字与黄色强调，保留协会 Logo。
- **多人分组**：自由添加、删除、重命名队伍；自动轮流出场，也能手动指定下一组。
- **自定义赛制**：每轮 15–300 秒；每题得分、跳过扣分、题库、音效和特效自由设置。
- **现场计分**：答对 / 跳过即时记录，显示各队累计答对数与得分，倒计时结束自动结算，实时排行榜，可导出 CSV。
- **随机不重复**：显示已用 / 总数与剩余词数，当前题目和跳过题均计入已用；抽完自动结算，可由主持人重置抽题进度。
- **游戏动效**：黄蓝背景缓动、漂浮光点、换词入场、计分反馈、倒计时提醒和庆祝彩纸；暂停时冻结背景，支持关闭特效与系统减少动态效果。
- **响应式与投影**：手机、平板、大屏均可使用，游戏界面支持全屏。
- **自动保存**：队伍、分数、设置、自定义词语和词库进度保存在当前浏览器的 localStorage 中，无账号、无服务器。

## 开始

### 本地运行

双击打开 `index.html` 即可。音效、全屏能力由浏览器和用户权限决定。

### GitHub Pages（main）

进入仓库 **Settings → Pages → Build and deployment**：
1. Source 选择 **Deploy from a branch**。
2. Branch 选择 **main**，目录选择 **/(root)**。
3. 保存后使用 Pages 提供的网址访问。

### Cloudflare Pages

Create application → Pages → Import repository，连接本仓库；Framework preset 选 **None**，Build command 填 **`exit 0`**，Build output directory 指向仓库根目录 **`.`**（即包含 `index.html` 的目录）。

### Vercel

导入仓库，Framework Preset 选 **Other**，不需要任何构建命令。

## 主持人操作

1. 在 **队伍** 区域添加队名，可直接修改；点击队伍可指定下一组。
2. 在 **上传 / 管理词库** 中导入词语，再调整限时、得分和跳过扣分。没有可用词语时不能开始。
3. 点击 **开始本轮**，在倒计时内点击 **答对** 或 **跳过**；每次操作会自动换题。
4. 时间到后查看该队本轮表现及实时排行，再让下一队上场。
5. **重置题库** 只清空抽题历史；**重置比赛** 清空积分、轮次和抽题记录（保留队伍与自定义词语）。
6. 赛前设置页也可 **重置抽词进度**；**重置队伍** 恢复默认两组并清空积分和比赛记录，保留词库与抽词进度；**清空词库** 删除全部词语和抽词进度，保留队伍、积分与比赛记录。重置前均需确认。

### 快捷键

| 按键 | 操作 |
| --- | --- |
| Space / Enter | 答对 |
| → | 跳过 |
| P | 暂停 / 继续 |
| H | 隐藏 / 显示题目 |
| Esc | 退出浏览器全屏 |

> 注意：键盘快捷键只在游戏进行中生效。屏幕可能被队友看到时，请让猜词者背对屏幕。
